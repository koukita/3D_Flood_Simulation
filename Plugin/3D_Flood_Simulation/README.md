# 3D_Flood_Simulation プラグイン

QGIS 3.44～4.2向けの洪水可視化プラグインです。標高ラスタ（DEM）から水面標高を計算し、浸水深を2DラスタおよびDEM地形の3Dビューで表示します。

## インストール

1. `3D_Flood_Simulation` フォルダーをQGISのユーザープラグインフォルダーへコピーします。
2. QGISのプラグイン管理画面で **3D_Flood_Simulation** を有効にします。
3. 画面上部のプラグインパネルを使用します。プラグインメニューの項目からパネルを表示／非表示にできます。

## 使い方

1. 標高ラスタをプロジェクトに追加し、パネルのDEM一覧で選択します。単バンドの標高ラスタ（GeoTIFFなど）に加え、国土地理院DEM PNGタイルを使えます。国土地理院DEMタイルをQGISの「データの解釈」で **MapTiler Terrain RGB** として読み込んだ場合は、同形式の値をプラグインが国土地理院の0.01 m単位に換算します。DEM一覧はQGIS標準のレイヤーコンボボックスを使い、プロジェクト内のラスタレイヤを自動表示します。
2. 最小値・最大値を必要に応じて設定します（初期値は1 mと30 m、アップダウンボタンの変更幅は10 mです）。基準値欄には標高を直接入力することもできます。基準値欄の左にある **描画中／描画停止** ボタンをオンにすると、浸水深ラスタの再計算を停止できます。オフに戻すと現在の表示範囲で再計算します。パネルを閉じるとプラグインの再計算を停止し、現在の浸水深ラスタはそのまま保持します。プラグインを無効にした場合も浸水深レイヤとそのデータファイルは削除せず、プロジェクトに残します。パネルを再表示すると現在の表示範囲で更新を再開します。
3. パネル1行目の **地図から標高値取得** を押して地図をクリックし、基準標高を設定します。国土地理院DEMタイルではQGISプロバイダのMapTiler Terrain RGB解釈値を国土地理院の標高値に戻して使用します。1行目にはDEM、描画切替、基準値、標高取得、3Dビューを、2行目には最小値・スライダー・最大値を表示します。
4. スライダー値を基準標高に加算した値を水面標高として、DEM各セルとの差から浸水深を計算します。計算範囲はマップキャンバスとDEMの重なる部分に限定します。国土地理院DEM PNGタイルは、基準値取得と同じくMapTiler Terrain RGB値を国土地理院の標高値に換算して使います。マップキャンバスの移動・拡大縮小後は操作が約0.7秒止まった時点で再計算し、処理負荷を抑えるため出力画像の長辺は最大512ピクセルです。ラスタ計算はバックグラウンドで行い、操作中は現在の浸水深ラスタを表示したままにします。表示範囲が再度変わった場合は古い計算結果を破棄し、最新の範囲だけを反映します。スライダー操作後の再計算は短い遅延で行います。浸水深ラスタの混合モードは乗算で、20 m以上はすべて「20 m以上」の色で表示します。
5. **3Dビュー**を押すと、QGIS標準の3Dビューを開きます。カメラは2Dマップキャンバスの表示範囲を基準に設定し、地形タイル1辺あたりの標高サンプル解像度は512 pxにします。浸水深ラスタも3Dビューに表示します。水面は現在のマップキャンバス範囲と同じ大きさの単一矩形ポリゴンとしてメモリ上に作成し、地表ではなく計算した一定の水面標高に配置します。水面は薄い水色、15%の不透明度で表示し、混合モードは乗算です。3D表示に対応した建物レイヤがある場合は、水面と建物の位置関係を確認できます。2Dマップキャンバスでは水面ポリゴンを非表示にします。

## 表示色

水深色は国土交通省の洪水浸水想定区域図で使われる区分（0.5 m、3 m、5 m、10 m、20 m）を参考に、黄色・橙色・赤色・紫色で表します。20 m以上は同じ紫色の区分として表示し、浸水していないセルはNoDataとして透明になります。

## 対応範囲とデータ

- QGIS 3.44～4.2
- 単バンドの標高ラスタ、またはQGISで標高値として解釈される標高PNGタイルレイヤが必要です。PNGタイルは「MapTiler Terrain RGB」など、使用するタイルに合ったデータ解釈を指定してください。
- DEM、基準標高、スライダー値は同じ標高単位（通常はメートル）で扱います。
- 3D表示はQGISの3D機能が利用可能な環境で使用してください。
